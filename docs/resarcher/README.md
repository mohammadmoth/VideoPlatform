# Research index

Research supporting the approved media-library design. The `resarcher` directory name is retained as requested.

- [Filesystem discovery](filesystem-discovery.md) — why watch events are hints, especially under WSL and `/mnt/d`, and how reconciliation, bounded scans, settling, polling, and Refresh provide correctness.

These studies informed [the library plan](../library-plan.md) and remain the rationale for the implemented discovery and collection behavior.
